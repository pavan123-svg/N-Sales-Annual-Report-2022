# N Sales Annual Report 2022

## Project Overview
This project analyzes sales performance and customer purchasing behavior using Microsoft Excel.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning
- Data Visualization

## Project Objectives
- Analyze monthly sales performance.
- Understand gender-wise purchasing behavior.
- Analyze age group contributions.
- Identify top-performing states.
- Compare shopping channels.

## Data Cleaning
- Removed duplicate records.
- Identified missing values.
- Cleaned extra spaces using TRIM.
- Standardized gender values.
- Corrected date and number formats.

## Data Analysis
- Monthly Sales Analysis
- Gender Analysis
- Age Group Analysis
- State-wise Sales Analysis
- Shopping Channel Analysis

## Dashboard Features
- KPI Cards
- Interactive Slicers
- Pivot Charts
- Sales Performance Insights

## Key Insights
- March recorded the highest sales.
- Women contributed 64% of purchases.
- Adult age group (30-49) contributed the most.
- Maharashtra, Karnataka and Uttar Pradesh were top-performing states.

## Conclusion
The analysis helps identify important customer segments and
sales channels for improving business performance.
